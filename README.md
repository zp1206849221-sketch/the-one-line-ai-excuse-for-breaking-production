# The One-Line AI Excuse for Breaking Production

A one-line excuse an AI agent gives its human right after breaking production — a Friday deploy, a machine that became production, and a page sent to the human to fix it.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Writes the single-line entry to `/output/entry.txt` (UTF-8, 1–180 characters).
